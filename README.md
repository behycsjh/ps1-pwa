**PS1 Mobile Emulator PRO** — это кроссплатформенный мобильный эмулятор PlayStation 1, разработанный как Progressive Web App (PWA). Приложение полностью адаптировано под мобильные устройства и позволяет запускать ретро-игры прямо в браузере или в виде установленного на экран приложения без необходимости постоянного подключения к сети.

---

## ✨ Основные возможности

* 📱 **Полная поддержка PWA:** Установка на домашний экран iOS/Android и автономная работа оффлайн (через Service Worker).
* 🔄 **Screen Orientation & Fullscreen API:** Автоматическое или ручное переключение в альбомный полноэкранный режим с блокировкой поворота экрана.
* 💾 **Локальная библиотека (IndexedDB):** Сохранение загруженных ромов игр прямо в память устройства без необходимости повторной выборки файлов.
* 💿 **Поддержка множества форматов:** Запуск образов игр `.bin`, `.iso`, `.cue`, а также сжатых форматов `.chd` и `.pbp`.
* ⚙️ **Кастомный BIOS:** Возможность загрузки собственного файла BIOS (`scph1001.bin`) для максимальной совместимости.
* 🎮 **Экранный сенсорный геймпад:** Виртуальные кнопки с тактильной отдачей (Haptic Vibration) и гибкой настройкой прозрачности и размера.
* 🕹️ **Поддержка физических геймпадов:** Автоматическое обнаружение Bluetooth и USB контроллеров через Gamepad API.
* 📺 **CRT-фильтр:** Ламповый эффект сканирующих строк (Scanlines) для воссоздания атмосферы игры на классическом телевизоре.
* ⚡ **Ускорение времени (Fast Forward):** Переключение скорости игры (x1 / x2).

---

## 🛠️ Технологический стек

* **HTML5 / CSS3 / JavaScript (ES6+)**
* **IndexedDB API** — для хранения ромов и сохраненных состояний.
* **Screen Orientation API & Fullscreen API** — для фиксации горизонтального ориентации экрана.
* **Service Worker** — для обеспечения работы PWA в оффлайн-режиме.
* **Vibration API & Gamepad API** — для управления и тактильного отклика.
